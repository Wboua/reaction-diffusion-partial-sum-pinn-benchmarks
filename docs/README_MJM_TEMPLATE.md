# Mediterranean Journal of Mathematics -- LaTeX package

`Main.tex` has been converted to the journal's Birkhauser `birkjour` structure.

## Required official class file
Place the **official `birkjour.cls`** from the Mediterranean Journal of Mathematics submission-guidelines download (`birkjour.zip`) in this directory before compiling. The class file is not modified or reproduced here.

## Compile
Typical local sequence:

```text
pdflatex Main.tex
bibtex Main
pdflatex Main.tex
pdflatex Main.tex
```

## Items that still require author verification
1. Corresponding author and active e-mail address.
2. E-mail addresses for other authors if they are to be published.
3. Complete city/address for the second affiliation if required.
4. Competing Interests statement.
5. Funding statement.
6. Accurate AI/LLM-use disclosure if the final manuscript falls outside Springer Nature's definition of AI-assisted copy editing.

No scientific content in the section files was intentionally changed during template conversion.
